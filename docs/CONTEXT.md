# docs/ — context

This directory holds the v1 design specs: architecture.md (stack, deployment, repo layout, Definition of Shipped), database.md (schema and data decisions), api.md (routes and the authorization model), notifications.md (reminder pipeline), and ui-ux.md (screens). Each doc records decisions *and* the alternatives rejected — read the rejections before proposing changes. Scope questions go through PRODUCT.md at the repo root, not through edits here.
